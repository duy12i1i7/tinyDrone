Please use the Arduino IDE software to open the source code by selecting the `XW-Drone.ino` file.

Note: You must use Arduino IDE version 2.3.x or higher to compile the code; older versions (such as 1.8.19) are not supported!

You are required to install the ESP32 board core (i.e., "esp32" by Espressif Systems) along with the necessary dependencies (such as MAVLink). Specifically, you must install version 3.3.1 of the ESP32 board core!! (This is crucial; failing to do so will result in compilation errors.)

For the board selection, you may choose either "ESP32 Dev Module" or "WeMOS D1 MINI ESP32."
